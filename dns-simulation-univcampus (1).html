DNS Record Types Reference Guide

RFC 1035 Standards

A Record Address Record

Maps a hostname directly to a 32-bit IPv4 address. Enables clients to contact destination servers by human-readable names.

www.univcampus.edu → 192.0.2.10

CNAME Canonical Name

Creates an alias pointing to another canonical hostname. Decouples service names from direct IP configurations and streamlines IP migrations.

web.univcampus.edu → www.univcampus.edu

MX Record Mail Exchanger

Specifies the Mail Transfer Agent (MTA) server responsible for accepting incoming email for the domain, with numerical priority preference.

univcampus.edu → mail.univcampus.edu (Priority: 10)

Learning Outcomes

Applied Computer Networks Assessment

After completing this simulation, the student should understand:

✔ How DNS maps human-friendly domain names to machine-routable IP addresses.
✔ The purpose and structure of A records for IPv4 host binding.
✔ The purpose and resolution mechanics of CNAME records as canonical aliases.
✔ The purpose of MX records and priority rankings in email routing.
✔ The recursive and iterative DNS resolution process step-by-step.
✔ How DNS caching prevents redundant network round-trips and reduces server load.
✔ What happens when a physical server IP address changes.
✔ Why a CNAME record does not need to change when the target server's IP changes.
